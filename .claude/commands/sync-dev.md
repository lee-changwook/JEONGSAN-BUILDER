# 변경사항 우선 코드 동기화

dev 브랜치에서 pull 받되, 충돌 발생 시 **파일 단위가 아닌 충돌 블록 단위**로 현재 변경사항을 우선 적용한다.

## 워크플로우

1. 현재 브랜치가 `dev`이면 중단하고 경고한다
2. `git status`로 커밋되지 않은 변경사항이 있는지 확인한다
3. 커밋되지 않은 변경사항이 있으면 `git stash`로 임시 저장한다
4. `git pull origin dev -X ours`를 실행한다
   - 충돌 없는 부분: dev의 변경사항 정상 반영
   - 충돌 블록: 현재 브랜치(ours)를 우선 적용
5. stash한 변경사항이 있으면 `git stash pop`으로 복원한다
6. 최종 `git status`와 `git log --oneline -5`로 결과를 보여준다

## 주의사항

- 스킬은 사용하지 않는다
- `git checkout --ours <파일>` 같은 파일 단위 덮어쓰기는 절대 사용하지 않는다
- `-X ours`는 **충돌 블록에만** 현재 브랜치를 우선 적용하는 merge 전략이다
- stash pop 시 충돌이 발생하면 사용자에게 알리고 수동 해결을 안내한다
